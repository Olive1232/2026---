# 目录与命名规范

本规范由 2026-10-04 用户同意的目录检查建议确定。项目根是包含 `project.godot` 的内层 `2026聚光灯/`。

更新：2026-10-07，v0.0.20 商店通道修复完成。

## 命名

- 自有文件和目录使用小写下划线：`monster_spawner.gd`、`main_menu.tscn`、`monster_rat.tres`。
- GDScript 类名与场景节点名使用 PascalCase：`MonsterSpawner`、`CollisionLayers`、`Player`。
- 函数 / 变量 / 信号使用小写下划线；常量使用大写下划线。
- 文件名对应主要类型或职责，避免 `fp_constants`、`temp_scene` 这类难以判断用途的名字。
- 中文文档名称保留；`assets/enemies/README.md`、第三方 `addons/` 的内部文件及 Godot / Git 配置文件保留各自惯例。
- GDScript 使用 UTF-8 无 BOM、LF、Tab 缩进，约定写入根目录 `.editorconfig`。

## 素材与迁移约定

- 正式美术按用途与怪种归类，同一怪物的模型、贴图和动画放在同一目录。模型接入仍是后续任务，当前怪物在运行时生成占位方块。
- `assets/prototypes/world_tileset/` 被网格库制作场景及网格地图原型引用，不能按旧文档中“未引用”的判断直接删除。
- `.uid` / `.import` 是资源的配套文件，迁移时保留 UID 并维护导入源路径；二进制资源通过 Godot 更新内部依赖。
- 新目录在有实际用途时创建。怪物美术交付目录暂用 `.gitkeep` 保留；不再保留无内容、无当前用途的 `UI/`、商店 / 房间 / 武器等空目录。
- 整理目录不改玩法、经济数值和存档格式。移动后检查 `project.godot`、`load` / `preload`、场景外部资源、导入记录和文档引用，并运行相关回归。
